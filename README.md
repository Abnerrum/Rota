# Rota — Plataforma Inteligente de Operações de Campo

MVP para gestão de ordens de serviço, equipes e planejamento de rotas.

## Recursos
- Dashboard operacional
- Cadastro de técnicos e ordens de serviço
- Mapa interativo com OpenStreetMap/Leaflet
- Distribuição automática de OS por proximidade
- API FastAPI
- Front-end responsivo
- Docker

## Executar
```bash
docker compose up --build
```
Acesse http://localhost:8000

## Roadmap
PostgreSQL/PostGIS, autenticação, OR-Tools/OSRM, app do técnico, frota, estoque, BI, notificações e IA operacional.
